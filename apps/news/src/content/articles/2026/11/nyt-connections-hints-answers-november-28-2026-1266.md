## Which Connections #1266 tiles fit two groups, and what to lock first

Six of the 16 tiles have a believable second home. Darn, Hem, Patch and Skirt all pass for sewing and clothing words, which spreads four tiles over three groups. Fudge and Cherry both read as sweet things, which spreads two tiles over two groups. Nuts can join that snack idea as a third, but no fourth treat sits on the board, so a sweets group never closes.

| Tile | Second group it tempts | Why it stays where it is |
|---|---|---|
| Darn | A mending set with Hem and Patch | It is a mild oath, like Blast, Fudge and Nuts |
| Hem | The same mending set, with Darn and Patch | It names the edge of cloth, so it joins Border, Rim and Skirt |
| Patch | The mending set, with Darn and Hem | Soul Patch is a phrase, so it joins Food, Mate and Music |
| Skirt | Clothing, beside Hem | It also means to pass along the edge of a place, which fits Edge |
| Fudge | Sweets, beside Cherry | It stands in for a stronger word, like Blast, Darn and Nuts |
| Cherry | Sweets, beside Fudge | A cherry is a classic reel symbol, with Bar, Bell and Seven |

The lock order follows how many rivals each group has:

1. **Slot machine symbols.** Only Bar, Bell, Cherry and Seven read as reel pictures, so the group is exactly four tiles with nothing spare.
2. **Soul ___.** Food, Mate and Music pair with Soul with no competing meaning, and Patch is the only tile left that can complete the phrase. Locking it pulls Patch out of the mending trap.
3. **Mild oaths.** With the first two groups gone, eight tiles remain. Blast, Fudge and Nuts are exclamations, which settles Darn as the fourth.
4. **Edge.** Border, Hem, Rim and Skirt are what is left.

Starting with Darn, Hem or Skirt is the risky route, because each one has an honest rival group. Starting with the slot machine tiles carries no such risk.
