## Where each Pips board starts on Nov. 18

Cells are named by row, then column, counted from the top left, so R1C1 is the top-left cell.

**Easy.** R2C3 and R3C3 each add up to 4 by themselves, so both cells hold a 4. Only one domino in the set carries a 4, and it carries two, so that domino lies across those two cells.

**Medium.** R1C3 and R1C4 add up to 5, yet no domino in the set totals 5, so the two cells belong to different dominoes. R1C4 touches only R2C4 and R1C3, which leaves R2C4 as its partner. R2C4 adds up to 5 on its own, and only one domino has a 5, so that tile covers R1C4 and R2C4 with the 5 below. R1C4 then holds a 1 and R1C3 has to be a 4.

**Hard.** R6C1 adds up to 4 and its only neighbor, R7C1, adds up to 0. One domino shows a 4 and a 0, so it fills those two cells, 4 on R6C1.

## Pips hints for Nov. 18, 2026

**Easy (five dominoes: 2-2, 3-6, 2-1, 1-5, 4-4)**

- Hint 1: R2C1 must be more than 5, and only one domino in the set has a 6.
- Hint 2: R2C3 and R3C3 each add up to 4 alone. Look for the domino that can supply a 4 twice.

**Medium (seven dominoes: 1-5, 2-1, 3-4, 6-1, 4-4, 0-2, 0-0)**

- Hint 1: R3C4 must be more than 5, so it holds a 6, and the set has one domino with a 6.
- Hint 2: R3C1, R4C1, R4C2, R4C3 and R4C4 add up to 5 across five cells, so most of them are small, and three halves in the set show a 0.

**Hard (sixteen dominoes on a ten-row board)**

- Hint 1: R1C2 touches only R1C1, and the two cells must be equal. Think about which dominoes show one value twice.
- Hint 2: Four halves in the set show a 0, and R2C1, R4C5 and R7C1 each add up to 0.
