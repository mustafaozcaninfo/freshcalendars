## LinkedIn's eight daily games

Descriptions follow LinkedIn's Help Center. Anyone can play, with or without a LinkedIn account, and there are no prizes; a streak counts your daily wins.

| Game | What you do |
|---|---|
| Queens | Place one queen in every row, column and colored region |
| Tango | Fill a grid with two symbols so each row and column holds an equal number of each |
| Zip | Draw one path that visits the numbers in order and fills every cell |
| Mini Sudoku | Fill a small grid so each row, column and shaded region has every number once |
| Pinpoint | Guess the category that links a set of words, with up to five clues |
| Crossclimb | Order a word ladder where each word changes one letter, then solve the top and bottom |
| Patches | Complete every shape in the grid from a set of clues |
| Wend | Connect letters to find the hidden words, using every letter once |

## Tips for the logic grids

**Queens.** Start with the smallest colored region. If a region sits entirely inside one row or column, no other region can place its queen in that line, so cross that line off for everyone else.

**Tango.** In LinkedIn's Tango, no more than two identical symbols sit next to each other in a row or column. Look for two in a row and mark the cells on both ends with the other symbol, then count: a line that already holds half of one symbol takes the other in every empty cell.

**Zip.** Work from both ends: the path must start at 1 and end at the highest number, and dead-end corners force the path's shape.
