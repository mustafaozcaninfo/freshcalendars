# apps/web — design preview only

This Astro app is a **local design sandbox**. It is **not** the production SSG.

Production HTML, meta, OG images, and print assets are generated by:

```bash
pnpm fc gen --year 2026
pnpm fc verify
pnpm fc sync-cdn
pnpm fc deploy --confirm
```

See [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).
